# GreyForge

Editor de bloques del equipo de robótica **Los Grises** para programar Arduino, Teensy, ESP32, LEGO SPIKE Prime y EV3.

- **Página de descargas:** https://eduardoag33.github.io/greyforge/
- **Descarga directa (Windows):** https://github.com/EduardoAG33/greyforge/releases/latest/download/GreyForge-Windows.exe

Este repositorio solo guarda las versiones publicadas y la página. La app instalada busca aquí sus actualizaciones
(`latest.json` de la última versión).
